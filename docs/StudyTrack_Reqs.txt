# StudyTrack — Requisitos

## 1. Requisitos Funcionais (RF)

### RF01 — Autenticação

**Quando** um usuário informar suas credenciais, **o sistema deverá** validar os dados e permitir o acesso quando as credenciais forem válidas.

### RF02 — Controle de acesso

**Quando** um usuário acessar o sistema, **o sistema deverá** disponibilizar somente as funcionalidades autorizadas para seu perfil.

### RF03 — Cadastro de estudantes

**Quando** um usuário autorizado cadastrar um estudante, **o sistema deverá** armazenar seus dados e vinculá-lo à respectiva turma.

### RF04 — Cadastro de disciplinas e turmas

**Quando** um usuário autorizado cadastrar uma disciplina ou turma, **o sistema deverá** armazenar as informações e permitir a associação entre professores, estudantes e disciplinas.

### RF05 — Registro de notas

**Quando** um professor registrar uma nota, **o sistema deverá** associá-la ao estudante, à disciplina e à avaliação correspondente.

### RF06 — Cálculo de média

**Quando** uma nota for registrada ou alterada, **o sistema deverá** recalcular a média do estudante na disciplina correspondente.

### RF07 — Registro de frequência

**Quando** um professor registrar a frequência, **o sistema deverá** atualizar o percentual de frequência do estudante.

### RF08 — Cadastro de atividades

**Quando** um professor cadastrar uma atividade, **o sistema deverá** armazenar sua descrição, prazo e disciplina.

### RF09 — Controle de atividades atrasadas

**Quando** o prazo de uma atividade for ultrapassado sem registro de entrega, **o sistema deverá** classificá-la como atrasada.

### RF10 — Dashboard do estudante

**Quando** o estudante acessar seu dashboard, **o sistema deverá** apresentar suas notas, médias, frequência, atividades, evolução e situação acadêmica.

### RF11 — Indicador acadêmico

**Quando** os dados acadêmicos de um estudante forem atualizados, **o sistema deverá** recalcular seu indicador de situação acadêmica.

### RF12 — Alertas

**Quando** o indicador acadêmico atingir uma situação de atenção ou risco, **o sistema deverá** apresentar um alerta ao estudante e ao professor responsável.

### RF13 — Dashboard do professor

**Quando** o professor acessar uma turma, **o sistema deverá** apresentar indicadores de desempenho dos estudantes.

### RF14 — Plano de recuperação

**Quando** um professor selecionar um estudante em situação de risco, **o sistema deverá** permitir a criação de um plano de recuperação.

### RF15 — Relatórios

**Quando** um professor ou coordenador solicitar um relatório, **o sistema deverá** apresentar informações consolidadas de desempenho, frequência e situação acadêmica.

# 2. Requisitos Não Funcionais (RNF)

### RNF01 — Desempenho

O sistema deverá carregar as principais páginas em até **3 segundos** em condições normais de utilização.

### RNF02 — Segurança

O sistema deverá armazenar senhas utilizando mecanismo de **hash seguro**, não permitindo seu armazenamento em texto puro.

### RNF03 — Controle de acesso

O sistema deverá impedir que usuários acessem funcionalidades ou dados que não estejam autorizados para seu perfil.

### RNF04 — Usabilidade

O sistema deverá possuir interface responsiva, permitindo sua utilização em computadores, tablets e smartphones.

### RNF05 — Privacidade

O sistema deverá restringir os dados acadêmicos de cada estudante aos usuários autorizados.

# 3. Regras de Negócio (RB)

### RB01 — Perfis de usuário

O sistema deverá possuir os seguintes perfis:

- Estudante;
- Professor;
- Coordenador.

### RB02 — Acesso do estudante

Um estudante poderá visualizar somente seus próprios dados acadêmicos.

### RB03 — Acesso do professor

Um professor poderá visualizar os dados acadêmicos dos estudantes vinculados às suas turmas.

### RB04 — Acesso do coordenador

Um coordenador poderá visualizar os indicadores das turmas sob sua responsabilidade.

### RB05 — Frequência mínima

Uma frequência inferior a **75%** deverá ser considerada uma situação de risco.

### RB06 — Média de atenção

Uma média inferior a **7,0** deverá ser considerada um indicador de atenção.

### RB07 — Baixo desempenho

Uma média inferior a **5,0** deverá ser considerada uma situação de risco.

### RB08 — Atividade atrasada

Uma atividade cujo prazo tenha terminado sem registro de entrega deverá ser considerada atrasada.

### RB09 — Classificação acadêmica

O sistema deverá classificar a situação acadêmica em:

- Normal;
- Atenção;
- Risco.

### RB10 — Atualização do indicador

O indicador acadêmico deverá ser atualizado sempre que ocorrer alteração em nota, frequência ou atividade relevante.

### RB11 — Plano de recuperação

Um estudante classificado como risco poderá possuir um plano de recuperação criado por um professor responsável.

### RB12 — Progresso do plano

O progresso do plano de recuperação deverá ser calculado de acordo com a quantidade de atividades concluídas.
