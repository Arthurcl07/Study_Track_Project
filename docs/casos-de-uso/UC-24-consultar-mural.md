# UC-24 — Consultar o Mural de Comunicados

- **Ator**: Estudante, Professor, Coordenador
- **Objetivo**: ler os avisos das turmas e dos cursos
- **Pré-condições**: usuário autenticado
- **Spec**: SPEC-025 · **Requisitos**: RF-34

**Fluxo principal**
1. Usuário abre Comunicados (ou uma notificação de comunicado).
2. Sistema lista só os comunicados do alcance dele, mais recentes primeiro.

**Pós-condições**: nenhuma alteração.
**Regras aplicadas**: RB-02, RB-03, RB-04, RB-26.
