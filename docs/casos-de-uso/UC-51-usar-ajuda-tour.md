# UC-51 — Usar a Ajuda e o Tour

- **Ator**: Todos os perfis
- **Objetivo**: aprender a usar o sistema
- **Pré-condições**: estar autenticado
- **Spec**: SPEC-059 · **Requisitos**: RF-65

**Fluxo principal**
1. No primeiro acesso, o sistema oferece o tour do perfil.
2. Usuário segue os passos ou pula.
3. Na página Ajuda, revê o tour e lê o manual do perfil.

**Fluxos alternativos**: rever o tour.

**Regras aplicadas**: —.
