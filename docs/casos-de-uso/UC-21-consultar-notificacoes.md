# UC-21 — Consultar Notificações

- **Ator**: Estudante, Professor
- **Objetivo**: saber o que mudou e pede atenção sem procurar em cada tela
- **Pré-condições**: usuário autenticado
- **Spec**: SPEC-022 · **Requisitos**: RF-31

**Fluxo principal**
1. Usuário vê no menu o número de notificações não lidas.
2. Abre Notificações; o sistema lista só as dele, mais recentes primeiro.
3. Abre uma notificação: ela fica lida e o sistema leva à tela relacionada; ou marca todas como lidas.

**Pós-condições**: leitura gravada.
**Regras aplicadas**: RB-02, RB-03, RB-23.
