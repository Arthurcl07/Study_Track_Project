# UC-44 — Exportar Relatório em Excel e PDF

- **Ator**: Professor, Coordenador
- **Objetivo**: levar o relatório para fora do sistema
- **Pré-condições**: ter turmas no escopo
- **Spec**: SPEC-049 · **Requisitos**: RF-58

**Fluxo principal**
1. Usuário filtra o relatório.
2. Escolhe Excel, PDF ou CSV.
3. Sistema gera o arquivo com os mesmos filtros.

**Fluxos alternativos**: —.
**Exceções**: filtro fora do escopo.
**Regras aplicadas**: RB-03, RB-04.
