# UC-49 — Acompanhar a Saúde do Sistema

- **Ator**: Administrador
- **Objetivo**: saber se algo quebrou antes de alguém reclamar
- **Pré-condições**: nenhuma
- **Spec**: SPEC-057 · **Requisitos**: RF-63

**Fluxo principal**
1. Administrador abre Saúde do sistema.
2. Sistema mostra o banco, o tempo das consultas principais e os erros recentes com o código.
3. Administrador acha o erro pelo código informado pelo usuário.

**Fluxos alternativos**: —.
**Exceções**: —.
**Regras aplicadas**: RB-22.
