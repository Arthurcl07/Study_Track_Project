# UC-22 — Simular Notas

- **Ator**: Estudante, Professor
- **Objetivo**: saber quanto o estudante precisa tirar nas avaliações que faltam para chegar a 6,0 e a 5,0
- **Pré-condições**: usuário autenticado; turma de período aberto
- **Spec**: SPEC-023 · **Requisitos**: RF-32

**Fluxo principal**
1. Estudante abre o painel (ou o professor, o dashboard da turma).
2. Sistema mostra, por turma, a nota necessária para 6,0 e 5,0 (RB-25).
3. Estudante digita notas hipotéticas e vê a média e a situação simuladas.

**Pós-condições**: nenhuma alteração (nada é gravado).
**Regras aplicadas**: RB-02, RB-03, RB-05, RB-25.
