# UC-45 — Acompanhar Evasão

- **Ator**: Coordenador, Administrador
- **Objetivo**: agir cedo com quem sumiu das aulas
- **Pré-condições**: turmas de período aberto
- **Spec**: SPEC-050 · **Requisitos**: RF-59

**Fluxo principal**
1. Usuário abre o painel de evasão.
2. Sistema lista os estudantes que sumiram, com a turma, as faltas seguidas e a última presença.
3. Coordenador recebe a notificação quando alguém entra no alerta.

**Fluxos alternativos**: filtrar por curso.
**Exceções**: —.
**Regras aplicadas**: RB-45.
