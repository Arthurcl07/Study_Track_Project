# UC-43 — Emitir Documentos Oficiais da Turma

- **Ator**: Professor, Coordenador, Administrador
- **Objetivo**: imprimir ata, diário de classe e lista de presença
- **Pré-condições**: turma no escopo; ata só com diário homologado ou período encerrado
- **Spec**: SPEC-048 · **Requisitos**: RF-57

**Fluxo principal**
1. Usuário abre a turma e escolhe o documento.
2. Sistema monta o documento com o cabeçalho da instituição.
3. Usuário imprime ou salva em PDF.

**Fluxos alternativos**: lista de presença para uma data escolhida.
**Exceções**: ata de turma com diário aberto.
**Regras aplicadas**: RB-03, RB-04, RB-24, RB-37.
