# Persona — Mariana Souza (Formato de Regras)

## Regra P-01 — Perfil do usuário
- Quando o usuário for Mariana Souza, o sistema deve reconhecer que ela é professora universitária, responsável por disciplinas de Programação e Banco de Dados.
- Quando Mariana for professora, o sistema deve considerar a necessidade de acompanhamento de múltiplas turmas e estudantes.

## Regra P-02 — Objetivo principal
- Quando Mariana acessar o sistema, ela deve conseguir acompanhar o desempenho geral da turma de forma rápida.
- Quando houver estudantes com dificuldades, o sistema deve destacá-los para priorização de acompanhamento.

## Regra P-03 — Visão geral da turma
- Quando Mariana acessar uma turma, o sistema deve apresentar o número de estudantes em situação Normal, Atenção e Risco.
- Quando houver dados consolidados, o sistema deve disponibilizar indicadores de desempenho, frequência e evolução.

## Regra P-04 — Identificação de estudantes em risco
- Quando um estudante apresentar dificuldades, o sistema deve sinalizar essa condição para a professora.
- Quando o estudante estiver em atenção ou risco, o sistema deve disponibilizar os dados que justificaram essa classificação.

## Regra P-05 — Acompanhamento de notas e frequência
- Quando Mariana consultar a turma, o sistema deve mostrar médias e frequências dos estudantes.
- Quando houver redução de desempenho, o sistema deve evidenciar a mudança para apoiar a intervenção pedagógica.

## Regra P-06 — Acompanhamento de atividades
- Quando houver atividades pendentes, o sistema deve informar Mariana quais estudantes ainda não concluíram as tarefas.
- Quando uma atividade estiver atrasada, o sistema deve destacar o status para facilitar a priorização.

## Regra P-07 — Apoio à decisão
- Quando Mariana precisar decidir em quais estudantes intervir, o sistema deve fornecer indicadores consolidados.
- Quando a decisão for tomada, o sistema deve permitir acesso rápido ao histórico e às condições do estudante.

## Regra P-08 — Planejamento pedagógico
- Quando Mariana acessar relatórios de turma, o sistema deve facilitar reuniões pedagógicas e acompanhamento institucional.
- Quando houver necessidade de análise comparativa, o sistema deve apresentar dados organizados por desempenho, frequência e situação acadêmica.

## Regra P-09 — Cenário de uso
- Quando Mariana acessar o dashboard da turma, o sistema deve exibir a distribuição: 21 estudantes em Normal, 8 em Atenção e 3 em Risco.
- Quando existirem estudantes em situação de risco, o sistema deve permitir a abertura de dados individuais para análise.

## Regra P-10 — Benefício esperado
- Quando Mariana utilizar o StudyTrack, ela deve reduzir o esforço de análise manual e priorizar o acompanhamento dos estudantes com maior necessidade.
- Quando o sistema fornecer indicadores relevantes, Mariana deve conseguir agir antes de uma reprovação.

---

## Resumo das regras
- Mariana precisa de uma visão geral eficiente da turma e dos estudantes em situação crítica.
- O sistema deve consolidar dados de notas, frequência, atividades e alertas para apoiar a decisão pedagógica.
- O sistema deve facilitar a identificação de estudantes em atenção e risco.
- O objetivo principal é ajudar Mariana a acompanhar grandes grupos de alunos de forma mais ágil e estratégica.
